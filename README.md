# CommunityScripts 🛠️

A curated collection of troubleshooting and security scripts for cloud platforms and on-premises infrastructure — used internally and shared openly with the community.

## 📁 Structure

```
CommunityScripts/
├── AWS/
│   ├── troubleshooting/
│   └── security/
├── Azure/
│   ├── troubleshooting/
│   └── security/
├── GCP/
│   ├── troubleshooting/
│   └── security/
└── ActiveDirectory/
    ├── troubleshooting/
    └── security/
```

## 🚀 Quick Start

Each script is self-contained with usage instructions at the top. Most require only the relevant CLI tool (AWS CLI, Azure CLI, gcloud, or PowerShell with RSAT).

## ⚠️ Disclaimer

Scripts are provided as-is for educational and operational use. Always test in a non-production environment first. Review IAM permissions before running any script.
